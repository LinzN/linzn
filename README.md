## Libraries and bridges

- [**midea-ac**](https://github.com/LinzN/midea-ac) – control Midea air conditioners over the local network, without the cloud
- [**midea2mqtt**](https://github.com/LinzN/midea2mqtt) – Midea air conditioners on MQTT
- [**snapmaker2mqtt**](https://github.com/LinzN/snapmaker2mqtt) – status and events of the Snapmaker U1 over MQTT
- [**wiim-java-api**](https://github.com/LinzN/wiim-java-api) – Java client for the WiiM HTTP API

Java artifacts are published to the [MirraNET Maven repository](https://builds.mirranet.de/plugin/repository/everything/), Linux packages to `apt.mirranet.de` – see [www.mirranet.de](https://www.mirranet.de/#infrastructure) for how to add them.
